# Dayfile

A daily log for food, drinks, activity, supplements and how you feel, built to hand to an AI.
Formerly Kept; the Xcode project, bundle ID and App Group keep that name on purpose so
existing users' data and widgets carry over.
Paid once, no ads, no accounts, no subscription, no analytics. Everything stays on the device.

- Log meals and drinks in plain words. There is deliberately no nutrition database: the AI the
  user shares with does the estimating, better than a manual lookup would.
- Recent entries become one-tap suggestions. One tap adds a glass of water.
- A five-face feeling scale with notes on energy, mood, sleep and digestion.
- A supplements and routines checklist with doses, reminders, rest days and streaks.
- Ask AI turns any day, week or month into a ready-made prompt with six templates: energy
  patterns, nutrition estimate, supplement review, hydration, activity, or a custom question.
- Home-screen and lock-screen widgets with one-tap water and quick-log buttons.
- Siri: "Log food in Dayfile", "Log water in Dayfile", "Mark Vitamin D done in Dayfile".
- CSV and full JSON export.

## Requirements

- macOS with Xcode 15 or newer (iOS 17 SDK).
- An Apple Developer Program membership to ship to the App Store.
- [XcodeGen](https://github.com/yonaskolb/XcodeGen) to produce the `.xcodeproj` from `project.yml`.

## Build

```sh
brew install xcodegen
xcodegen generate
open Kept.xcodeproj
```

Then select your team under **Signing & Capabilities** and run on a simulator or device.

If you would rather not install XcodeGen: create a new iOS App project in Xcode named `Kept`
(SwiftUI, Swift), delete the template `ContentView.swift` and `KeptApp.swift`, and drag the
`Kept/` folder's contents into the project. Add `KeptTests/` to a new Unit Testing Bundle target.
Set `ITSAppUsesNonExemptEncryption` to `NO` in the target's Info tab.

## Test

```sh
xcodebuild test -project Kept.xcodeproj -scheme Kept \
  -destination 'platform=iOS Simulator,name=iPhone 15'
```

The tests cover streak math (including month, year, and leap-day boundaries), `DayKey` encoding,
and JSON persistence round-trips.

## Layout

```
project.yml                 XcodeGen spec (targets, Info.plist keys, bundle ID)
Kept/
  KeptApp.swift             @main entry point
  KeptShortcuts.swift       Siri / Shortcuts phrases
  PrivacyInfo.xcprivacy     Privacy manifest (no tracking, no data collected)
  Assets.xcassets/          App icon (generated by scripts/make_icon.py) and accent color
  Models/                   DayKey, Habit, LogEntry, KeptSettings  (shared with the widget)
  Logic/                    Streaks, reminders, log insights, AI export, CSV
  Store/                    HabitStore plus JSON files in the App Group (shared with the widget)
  Shared/                   App Group id, AppIntents           (shared with the widget)
  Services/                 ReminderScheduler (UserNotifications)
  Views/                    SwiftUI screens
KeptWidget/                 WidgetKit extension: home-screen and lock-screen widgets
KeptTests/                  XCTest unit tests
scripts/make_icon.py        Regenerates the 1024x1024 icon with no dependencies
docs/                       Submission runbook, listing copy, privacy policy
```
